## تغطية إضافية

- أرقام عربية وفارسية، عمليات منطوقة، LaTeX متداخل، تكاملات مركبة ذات حدود مستقلة.
- مشاركة تعريف الدالة ومشتقتها ومعاملاتها؛ بقاء جزء ناجح عند فشل آخر، ومتابعات المنحنى والتفصيل.
- أنظمة خطية 2×2 و3×3، ورفض نظام غير خطي، واستخدام الجذور عدديًا دون ربط x في دالة جديدة.

- وحدات الزوايا، مصفوفة4×4، المجسمات، الإحصاء والثنائي والطبيعي والتوافيق.
- قوة عدد عقدي وجذوره ومرافقه ومقلوبه وموقعه في المستوي.
- رفض المعلمات غير المقبولة دون قصّها: n=12.5، p=1.1، وانحراف معياري سالب.
- أس قابل للتحرير من لوحة فعلية، خروج بالمسافة، Enter وShift+Enter، وإدراج كسر حقيقي من اللوحة.

- Escape في نافذتين متداخلتين، احتجاز Tab وإعادة التركيز، أسهم قائمة الأدوات، وتفضيل تقليل الحركة.

## إعادة التشغيل

اختبارات Node لا تحتاج متصفحًا أو شبكة بعد تثبيت التبعيات:

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 5173
```

اختبارات المتصفح اختيارية، فلا أُضيف Playwright إلى تبعيات التطبيق الأصلية. وفّر Playwright/Chromium محليًا، أو ثبت اختياريًا دون تعديل package/lock:

```bash
npm install --no-save --package-lock=false playwright-core @sparticuz/chromium
npm run test:browser

# متصفح موجود مسبقًا؛ أو استخدم PLAYWRIGHT_MODULE لمسار module خارجي
CHROMIUM_EXECUTABLE=/path/to/chromium \
APP_URL=http://127.0.0.1:5173/ TEST_OUTPUT=test-results/http \
npm run test:browser

CHROMIUM_EXECUTABLE=/path/to/chromium \
APP_URL="file://$PWD/dist/index.html" TEST_OUTPUT=test-results/file \
npm run test:browser
```

`@sparticuz/chromium` مناسب لبيئة Linux المدعومة؛ على الأنظمة الأخرى استخدم Chromium المتوافق عبر `CHROMIUM_EXECUTABLE`. قد تحتاج مكتبات نظام تشغيل للمتصفح، وهي ليست موارد يحتاجها ملف التطبيق نفسه.

بعد نجاح التحقق: `python3 tools/package.py`. تحقّق من الملفين في `deliverables/checksums.sha256`، ولا تستعمل نسخة تسليم قديمة قبل إعادة بنائها.
