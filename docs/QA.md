## تغطية إضافية

- أرقام عربية وفارسية، عمليات منطوقة، LaTeX متداخل، تكاملات مركبة ذات حدود مستقلة.

- أنظمة خطية 2×2 و3×3، ورفض نظام غير خطي، واستخدام الجذور عدديًا دون ربط x في دالة جديدة.
- حالات حدودية كانت تكشف تقديرًا زائفًا: log(x) عند0، وsin(x) عند±∞، وsin(1/x) عند∞؛ رفض نتيجة x·sin(x) غير المؤكدة بدل عرض آخر عينة.
- استبعاد الطرف غير الحقيقي لمجال الجذر، وأقطاب 1/x و1/x² والاقتراب الأحادي.
- وحدات الزوايا، مصفوفة4×4، المجسمات، الإحصاء والثنائي والطبيعي والتوافيق.
- قوة عدد عقدي وجذوره ومرافقه ومقلوبه وموقعه في المستوي.
- رفض المعلمات غير المقبولة دون قصّها: n=12.5، p=1.1، وانحراف معياري سالب.
- أس قابل للتحرير من لوحة فعلية، خروج بالمسافة، Enter وShift+Enter، وإدراج كسر حقيقي من اللوحة.
- حفظ يدوي ونسخ وإعادة تحميل ومحادثة جديدة ومسح مستقل وسجل تالف.
- Escape في نافذتين متداخلتين، احتجاز Tab وإعادة التركيز، أسهم قائمة الأدوات، وتفضيل تقليل الحركة.
- عرض 320/360/390 بكسل بلا تجاوز أفقي للمستند؛ جدول/مصفوفة كبيرة تتمرر داخليًا.
- OCR حقيقي لصورة مولدة من نص عربي ومعادلة مطبوعة، مراجعتها وتصحيحها والموافقة قبل الإرسال؛ وإلغاء أثناء التهيئة.

### مراجعة سابقة: الصيغ المركبة والمتابعة

أعيد تدقيق النسخة السابقة قبل التعديل، وسُجلت15 ملاحظة تشخيصية في `qa/matrix-followup-audit.json` مع نواتج قبل/بعد؛ **هذه ملاحظات لا عداد اختبارات**، وتتضمن صيغًا كانت ناجحة أصلًا كضوابط. كشفت خلط طلب «محدد A وأثر B»، وتجاهل العمود الأخير/السابع، وغياب تنسيق الجمل cases وبعض أفعال الضرب.

أضيفت20 حالة مؤلفة إلى مجموعة المصفوفات، و17 فحصًا وظيفيًا/عرضيًا، أي37 زيادة فوق124 السابقة. بلغت المجموعة حينها161، والمجموع757؛ الأعداد الحالية في الجدول أعلاه. تتضمن الإصلاحات:

- كل عملية مستقلة مرتبطة بالاسم الصريح وبترتيب المصدر، بما فيها تكرار المحدد لمصفوفتين. تبقى علامة «أ)» لكل جزء فرعي ولا يُحجب أثرB المستقل إذا فشل محددA.
- الاحتفاظ بالشجرة الحسابية S=det(A)+tr(B)، وطلب فصل إثبات/تعريف مركب ملتبس بدل تفسير الهدف معطى أو إسقاط جزء منه.
- كرامر/غاوس من cases/aligned والكسور في أول معادلة والمجاهيل س/ص/ع. ينضد السؤال نفسه كتلة كاملة، لا أجزاء أوامر ناقصة برسالة تعذّر عرض. تمييز أخطاء التنضيد بـ`data-math-error` جعل اختبارات المتصفح تكشف fallback أيضًا، لا class KaTeX فقط.
- النشر بحسب العمود الأخير حقيقةً، ورفض الرقم غير الصالح، وعدم الخلط بين «صف» و«مصفوفة». أضيف فحص صريح لعبارة «المصفوفة … العمود 2» للحد من هذا التداخل.
- k معطى حقيقي دقيق ومحمي في الحفظ، وليس قيمة محدد سابقة. k=0 يصفّر كل العناصر، والجذر والكسر يبقيان دقيقين؛ تستعيد اللوحة قيمةk وتتطلب زر الحل بعد تعديلها.
- عدم تحويل الفعل «اضرب» إلى «ا*»، وعدم سرقة «التوزيع الغاوسي» لصالح محرك المصفوفات، وعدم إعادة تعريف tuple هندسي على أنه مصفوفة سابقة.

```bash
# متصفح موجود مسبقًا؛ أو استخدم PLAYWRIGHT_MODULE لمسار module خارجي
CHROMIUM_EXECUTABLE=/path/to/chromium \
APP_URL=http://127.0.0.1:5173/ TEST_OUTPUT=test-results/http \
npm run test:browser

CHROMIUM_EXECUTABLE=/path/to/chromium \
APP_URL="file://$PWD/dist/index.html" TEST_OUTPUT=test-results/file \
npm run test:browser
```

`@sparticuz/chromium` مناسب لبيئة Linux المدعومة؛ على الأنظمة الأخرى استخدم Chromium المتوافق عبر `CHROMIUM_EXECUTABLE`. قد تحتاج مكتبات نظام تشغيل للمتصفح، وهي ليست موارد يحتاجها ملف التطبيق نفسه.

بعد نجاح التحقق: `python3 tools/package.py`. تحقّق من الملفين في `deliverables/checksums.sha256`، ولا تستعمل نسخة تسليم قديمة قبل إعادة بنائها.
