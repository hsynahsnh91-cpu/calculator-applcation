# ملفات التسليم

- **calculator.html**: التطبيق الكامل في ملف مستقل. افتحه بمتصفح حديث؛ لا يحتاج خادمًا أو اتصالًا أثناء الاستخدام. يشمل الخطوط وقارئ الصور المحلي وموارد OCR. حجمه نحو17.03 ميغابايت بسبب تضمين الموارد بدل تنزيلها.
- **calculator-source.zip**: المشروع الكامل القابل للتطوير، مع المصدر والمحركات والاختبارات والتوثيق وبيانات OCR والتراخيص. لا يشمل node_modules أو الملفات المؤقتة.
- **checksums.sha256** و**manifest.json**: أحجام الملفين وبصماتهما للتحقق من سلامة النسخ.

داخل حزمة المصدر: اقرأ README.md للتشغيل وdocs/QA.md للاختبارات والحدود. البناء: `npm ci && npm run build`. يحتاج تثبيت تبعيات المصدر شبكة عند الإعداد الأول فقط، لا أثناء تشغيل HTML المبني.

OCR مساعد للنص المطبوع ويجب مراجعة استخراجه قبل الحل. الميكروفون لا يظهر إلا عند توفر تعرّف عربي محلي مثبت؛ لا يستخدم بديلًا خادميًا. قد تمنع بعض تطبيقات معاينة الملفات تشغيل JavaScript/WASM؛ افتح HTML في متصفح كامل.

## تحديث 2026-10-16 — الاحتمالات والإحصاء

يتضمن لوحة احتمالات وإحصاء عائمة متجاوبة ومتصلة بالمحادثة، الفضاء العيني قبل الحساب والأوضاع الثلاثة للسحب، ألوانًا وهدفًا حيًا وترتيب كرات عشوائيًا للعرض، والمقارنات «أو أكثر / أقل». يدعم قواعد الأحداث والشرطي والاحتمال الكلي وبايز والاستقلال، وقوانين المتحولات وعزومها، وجداول التكرارات والمدرج التكراري، مع كسور دقيقة وجسور إلى الاشتقاق والمصفوفات والحساب العلمي.

تحسينات أويلر وديموافر والأشكال الثلاثة وℝ/ℂ والتحويلات السابقة محفوظة، وكذلك التطبيق المستقل دون اتصال وقارئ الصور المراجَع.

التحقق: TypeScript صارم، و596 اختبار Node، و100 اختبار متصفح لكل من HTTP والفتح المباشر file://؛ لا طلبات خارجية أو أخطاء غير معالجة في المسار المفحوص. شاشات محاكاة هاتف 320/360/390 بكسل، وليست أجهزة فعلية. راجع README وdocs/QA وdocs/PROBABILITY داخل المصدر للأمثلة والحدود.

## إضافة السؤال المدرسي واللهجات ومراجعة الرموز

أُصلح سؤال المنهاج السوري ذي المعلم وتعريفات z_A وz_B وz_C وطلبات الشكل الأسي والاستنتاج بالمرافق. تشمل الإضافة حفظ المعطيات بين الطلبات، فصل التقديم عن المطلوب، دعم صيغ لهجية شائعة، ومعاينة رياضية للنص المستخرج من الصورة قبل الإرسال. الصور تظل بحاجة إلى مراجعة بشرية، ولا يوجد ضمان لتعرف صحيح لكل جذر أو خط يدوي. التفاصيل في docs/TEXTBOOK.md داخل المصدر.

## ترقية الهندسة الفراغية

لوحة متجاوبة بستة تبويبات داخل المحادثة، وخانات ثلاثية واضحة، وأمثلة ومدخلات تغيّر الحل فعلًا. تشمل الارتباط الخطي والاستقامة والاستواء، مركز الأبعاد والتجميع، الجداء السلمي، الكرة، المستقيمات والمستويات وأوضاعها وأبعاد النقاط، والحجوم مع ربط الارتفاع بقانون الهرم. رسوم SVG قابلة للتدوير وجسور للمصفوفات والحساب العلمي، مع تحقق مستقل مشروط وحماية الحالات المنعدمة. دليل الصيغ والحدود في docs/GEOMETRY.md.

## الصياغة المدرسية والسياق

يتضمن الإصدار وثيقة سؤال تحفظ العنوان والمعطيات والترقيم، وبطاقات الطلبات، ونقل الجذور والصناديق والتجربة المستقلة، وطرقًا مدرسية محددة مع رفض الادعاءات غير المبرهنة. دليل القدرات داخل +، والتفاصيل وما لا يحله في docs/CURRICULUM.md. لا نموذج توليدي ولا API خارجي. القيود المرجعية موضحة؛ لا ادعاء بمطابقة كتاب وزاري كامل لم يتيسر الحصول على متنه.
