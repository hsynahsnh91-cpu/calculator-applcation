# حوار رياضي — رياضياتك، خطوة بخطوة

واجهة محادثة عربية واحدة للبكالوريا السورية، مبنية على React 19 وTypeScript وVite. تعمل بمحركات رياضية محلية حتمية؛ **لا يوجد نموذج محادثة توليدي، ولا API خارجي، ولا خادم حسابات**.

## التشغيل المباشر

افتح `deliverables/calculator.html` في متصفح حديث. الملف مستقل: JavaScript وCSS وخط Cairo وخطوط الرياضيات وقارئ OCR وWASM وبيانات العربية والإنجليزية مضمنة فيه. لا يحتاج تثبيتًا أو اتصالًا أثناء الاستخدام.

بعض متصفحات الهواتف وتطبيقات معاينة الملفات تمنع تشغيل Web Workers/WASM أو حفظ البيانات في الملفات المحلية. افتح الملف في متصفح كامل. إن كانت سياسة المتصفح تمنع `file://`، شغّل معاينة المشروع محليًا كما يلي.

## تطوير المشروع وإعادة البناء

تحتاج Node.js المتوافق مع Vite 7: الإصدار 20.19+ أو 22.12+.

```bash
npm ci
npm run dev -- --host 0.0.0.0

npm run typecheck
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 5173
```

يتطلب `npm ci` تنزيل التبعيات عند إعداد المصدر للمرة الأولى. **هذا ليس اعتمادًا على الإنترنت أثناء تشغيل التطبيق المبني**. ناتج البناء هو `dist/index.html` فقط. لتحديث حزمة التسليم بعد الاختبارات: `python3 tools/package.py`.

## الاستخدام

- اكتب السؤال بالعربية أو امزجها بالرموز وLaTeX في مربع واحد. يدعم الأرقام العربية والفارسية وصيغًا شائعة من الكلام السوري والفصيح.
- `Enter` يرسل، و`Shift+Enter` يضيف سطرًا. كتابة `^` بعد أساس تنشئ أسًا رياضيًا قابلًا للتحرير فعليًا، لا رمزًا نصيًا فقط. تخرج المسافة من الجزء الرياضي لمتابعة العربية.
- من زر **+**: صورة، لوحة رياضية، لوحة الاحتمالات والإحصاء، لوحة الهندسة الفراغية، بنك القوانين، سجل النتائج، DEG/RAD/GRAD، صوت واهتزاز، تعديل الاسم، محادثة جديدة ومسح المحادثة.
- اسم الترحيب قابل للتعديل ومحفوظ على الجهاز فقط. لا توجد صفحات أقسام أو ترويسة أو تنقل سفلي.
- يبدأ كل جواب بصندوق **الجواب النهائي**، ثم الخطوات والمرئيات الملائمة والمتابعات والنسخ والحفظ. شارة **تم التحقق** مشروطة بفحص مستقل ناجح؛ ليست زينة ثابتة.
- الطلبات المرقمة `أ) ... ب) ...` أو `1) ... 2) ...` تشترك في التعريفات، ويمكن متابعة الدالة أو المصفوفة السابقة. فشل جزء لا يمحو الأجزاء المكتملة.
- الصور تُقرأ محليًا وتعرض نصًا قابلًا للتصحيح. يجب الموافقة على النص وإرساله يدويًا. OCR للنص المطبوع مساعد فقط؛ لا يضمن قراءة الخط اليدوي أو الكسور والأسس المعقدة.
- الميكروفون **يُخفى** إلا إذا دعم المتصفح Web Speech محليًا وكانت حزمة `ar-SA` مثبتة بالفعل. يُضبط `processLocally=true`، ولا يوجد بديل يتصل بخادم، ولا تنزيل تلقائي لحزمة لغة.

## صياغة المنهاج السوري واللهجات والصور

يفصل المحلل بين **المعطيات والمطلوب**: يحفظ تعريفات z_A وz_B وz_C ثم يطبق الطلب على الاسم المذكور، لا على أول نقطة في المقدمة. لا يقسم المعلم `(O; …)` عند فاصلتِه الداخلية، ويدعم نسخ Markdown والترقيم وLaTeX واللاحقات والجذور المتجاورة مع i.

```text
في معلم متجانس (O; u,v)، نتأمل النقاط ذات الأعداد العقدية:
z_A=1+i√3
z_B=2
z_C=1-i√3
المطلوب:
1. اكتب z_A بالشكل الأسي، ثم استنتج الشكل الأسي للعدد z_C.
```

الجواب: z_A=2e^(iπ/3)، ثم z_C=2e^(−iπ/3). توضح الخطوات الطويلة والربع والعمدة بالراديان، ثم تستنتج C بالمرافق **بعد فحص العلاقة من المعطيات**. الصيغة المطلوبة صريحة في النتيجة، وليست زاوية θ غير معوضة فقط.

تدعم طبقة الكلمات صيغًا شائعة مثل «بدي حوللي»، «عايز/عاوز»، «أبغى/أبي»، و«بغيت نكتب/نحسب»، مع ثبات المعنى الرياضي. لا يعني ذلك ضمان فهم كل لهجة أو كل مسألة؛ المعطيات الناقصة أو الصيغ الملتبسة ما زالت تستدعي توضيحًا.

للصور: يظل النص قابلًا للتصحيح والموافقة، وأضيفت معاينة رياضية حية للرموز قبل إدراج السؤال. لا يُصحّح v إلى جذر أو1 إلىi بالتخمين، ولا تحل الصورة دون المراجعة والإرسال. دليل المثال والأسباب والحدود: [docs/TEXTBOOK.md](docs/TEXTBOOK.md).

## السؤال المدرسي: مقدمة وترقيم ونتائج مترابطة

من **+ ← دليل قدرات التطبيق** اقرأ ما يحله الإصدار وما لا يحله، ثم أدرج مثالًا دون إرساله تلقائيًا. المرجع التفصيلي: [docs/CURRICULUM.md](docs/CURRICULUM.md).

- العنوان والدرجة ليسا طلبًا. المقدمة تحفظ التعريفات، والطلبات تحتفظ بأرقامها وعناوينها الأصلية، بما فيها I/II وأ/ب و• و«ثم».
- لكل طلب مرقم بطاقة، مع الجواب النهائي أولًا وخطواته ورسومه. يظهر توضيح واحد مع بقاء النجاحات، ولا يعاد استعمال نتيجة قديمة عند فشل طلب يعتمد عليه.
- **S=z1^12+z2^12** بطريقة أسية يحسب مقدارًا حقيقيًا من الأعداد المعطاة؛ مع1±i√3 النتيجة8192. جذرا معادلةz ينتقلان إلى الطلب التالي باسمَيz1 وz2، ولا توجد إجابة محفوظة لهذا السؤال.
- الصندوقان المسميان واختيار أحدهما والتجربة الجديدة نماذج منفصلة. في مثال3/2 و2/4: الاحتمال7/15 ثم بايز9/14، وبعد إعادة الكرة والسحب منU1 يكون قانون عدد البيضاء{3/10,3/5,1/10} وأمله4/5.
- العلاقة التدريجية الأفينية المكتوبة مباشرة، والمتتالية المساعدة وبرهان صيغتها بالتدريج، والوجود والوحدانية لكثيرات حدود محدودة، مسارات استدلال لا زينة حول عينات عددية.
- المماس لا يفترض نقطة0، والتحقق عند قيمة محددة تعويض فعلي قد يرفض الادعاء. لا يُتخذ الاستقلال المدعى فرضًا، ولا يظهر لون أحمر افتراضي لحدث ناقص.
- التقريب العددي مغلق حتى يُطلب. شارة التحقق تخص فحصًا مستقلًا ناجحًا للنتيجة المعروضة، ولا يحل فحص مجموع محل التحقق من عبارة الحد العام.

لا يوجد حل عام للبرهان أو المعادلات التفاضلية أو المتراجحات أو دراسة كاملة لأي تابع. أدوات المصفوفات والتقريبات وبعض الكميات التكاملية إضافية، وليست إثباتًا لورودها في طبعة الكتاب. لم يتيسر الحصول على متن طبعة وزارية كاملة في هذه المراجعة؛ حدود الادعاء والمراجع موثقة صراحة.

## الهندسة الفراغية — خانات متجاوبة ونتائج مرتبطة بالمحادثة

افتح **+ ← لوحة الهندسة الفراغية**، أو زر **لوحة الهندسة** في جواب سابق. التبويبات الستة داخل نافذة الأداة هي **المجسمات، الأشعة، النقاط والمراكز، المستويات، المستقيمات، الكرة**؛ وليست صفحات أقسام أو تنقلًا جديدًا. تظهر3 خانات واضحة x وy وz لكل نقطة أو شعاع، مع حقول الأوزان والاتجاهات والمعادلات عند اختيار العملية.

- تغيير خانة أو تحميل مثال آخر يبني سؤالًا جديدًا فعليًا؛ **حل في المحادثة** يستعمل Worker، و**إدراج في السؤال** يبقيه مسودة قابلة للتعديل دون إرسال.
- إحداثيات الشعاع ونظيره وطويلته، والعمليات على الأشعة، والارتباط الخطي لشعاعين أو ثلاثة مع علاقة غير تافهة واختزال غاوس. استقامة3 نقاط واستواء4 نقاط لا يُختزلان إلى فحص بصري.
- مركز الأبعاد لنقطتين إلى أربع نقاط بأوزان صريحة، والتجميع وتلاقي المتوسطات/الواصلات مع مراكز الوجوه، مع تمييز الانطباق والحالات التي لا تعرّف مستقيمًا وحيدًا.
- الجداء السلمي بالإحداثيات أو من الطويلتين والزاوية بوحدتها، وناظم المستوي ومعادلته، والتمثيل البارامتري للمستقيم بوسيط واحد، وأوضاع المستويين والمستقيم والمستوي والمستقيمين، بما فيها التخالف.
- بعد نقطة عن مستوٍ أو مستقيم مع المسقط العمودي، ومعادلة الكرة من مركز ونصف قطر أو من قطر أو من معادلة موسعة، وحجوم المجسمات ورباعي الوجوه ومتوازي السطوح.
- للهرم العام: الحجم من **مساحة القاعدة والارتفاع** دون افتراض شكل القاعدة. يمكن استعمال البعد السابق ارتفاعًا؛ المساحة الكلية لهرم غير محدد لا تُخترع.
- رسم إسقاطي متجاوب قابل للتدوير مع الإحداثيات الدقيقة في جدول، وشارة التحقق فقط عند وجود فحص مستقل. يحتفظ فتح جواب قديم بمعطيات ذلك الجواب الأصلية، لا بمعطيات آخر مثال.
- جسور إلى المصفوفات وجملة الوسيطين والحساب العلمي، مع حفظ الأسماء والمتابعات دون الخلط مع احتمال سابق أو عدد عقدي.

```text
جد الشعاع AB حيث A(1,2,3) وB(4,6,3)
هل النقاط A(0,0,0) وB(1,0,0) وC(0,1,0) وD(1,1,0) مستوية؟
A(0,0,0)، B(3,0,0)، C(0,3,0)، جد مركز الأبعاد المتناسبة، الأوزان=[1,1,1]
جد تقاطع المستقيم D: (x,y,z)=(0,0,0)+t*(1,1,1) والمستوي P: x+y+z-3=0
جد بعد M(1,2,3) عن المستوي P: 2x-y+2z-5=0
جد معادلة الكرة مركزها K(1,2,3) ونصف قطرها r=2
احسب حجم هرم مساحة القاعدة area=6 والارتفاع h=3
```

تعمل الصيغ المترية في معلم متعامد متجانس. الإحداثيات والكسور والجذور البسيطة تحسب في مجال جبري دقيق محدود؛ الجذور المتداخلة العامة أو المعلم غير المتعامد بلا جداءات أساس تحتاج توضيحًا. الرسم ليس برهانًا، والجسر إلى المصفوفات عددي مع بقاء المصدر الجبري محفوظًا. الصيغ والحدود ومسؤوليات الوحدات: [docs/GEOMETRY.md](docs/GEOMETRY.md).

## الاحتمالات والإحصاء — لوحة متصلة بالمحادثة

من **+ ← الاحتمالات والإحصاء** تفتح لوحة هادئة بخمسة تبويبات: السحب، الأحداث، المتحولات، التوزيعات، والإحصاء. تتاح الأعداد والألوان والهدف ونمط السحب والمقارنة من حقولها مباشرة، مع إدراج سؤال قابل للتعديل أو حله في المحادثة نفسها. ويمكن إعادة فتح اللوحة من جواب سابق بمعطيات ذلك الجواب تحديدًا.

- **الفضاء العيني أولًا:** السحب معًا يستعمل التوافيق، والمتتالي دون إعادة التراتيب، والمتتالي مع إعادة القوى. قائمة نمط السحب تشرح اختلاف الترتيب والتكرار.
- ترتيب الكرات ودورانها عشوائيان للعرض فقط؛ لا يتغير العد أو الاحتمال. يتبع لونُ الهدفِ مؤشرَ اللون وصيغةَ p مباشرة. للأعداد الكبيرة يستعمل العرض تمثيلًا نسبيًا محدودًا بـ80 كرة مع تنبيه واضح.
- **بالضبط / أو أكثر / أقل / أكثر / أو أقل** مقارنات مختلفة للعدد المطلوب، وليست إعادة تسمية لاحتمال وقوع الحدث أو متممه.
- قانون الاحتمال الكلاسيكي للحالات المتساوية الاحتمال، المتمم، الاتحاد والتقاطع والتنافي، الشرطي، الاحتمال الكلي وبايز، والاستقلال مع رفض المعطيات المتناقضة أو الشروط ذات الاحتمال صفر.
- السحب المرتب والشرطي وتركيبات عدة ألوان، وشجرات تضرب احتمالات المسار وتجمع المسارات المناسبة. ليس كل سحب ثنائيًا: دون إعادة لا يُستبدل القانون فوق الهندسي بالثنائي.
- مجموعة القيم الفعلية وقانون كامل مجموعه1، الأمل والعزم الثاني والتباين والانحراف، وتحويل أفيني للمتحول، واستقلال متحولين من قانون مشترك كامل وهوامشه.
- جداول تكرارات وكسور دقيقة، متوسط ووسيط ومنوال وتباين وصفي وتباين عينة مميزان، و**مدرج تكراري** حقيقي. يبقى منحنى كثافة التوزيع الطبيعي منحنى كثافة، لا يُسمى مدرجًا.
- متابعات مبنية على سياق منظم، لا على لصق السؤال القديم: قانون المتحول ← كثيرة حدود مولدة ← الاشتقاق، وجدول التكرارات ← مصفوفة، والاحتمال الدقيق ← حساب علمي. يحتفظ تحديث شجرة بايز بمعنى B الحالي، والشرطي المرتب بتعريف حدث الهدف والشرط.

```text
كيس فيه 3 كرات حمراء و5 بيضاء سحبت كرتان معًا، احسب احتمال كرة حمراء واحدة أو أكثر
P(A)=1/2، P(B)=1/3، P(A∩B)=1/6، احسب الاتحاد
الاحتمال الكلي q=[1/3,2/3]، p=[1/2,1/4]
المتحول X=[0,1,2]، p=[1/4,1/2,1/4]، احسب الأمل والتباين
القيم=[1,2,3]، التكرارات=[2,3,1]، احسب المتوسط والمدرج التكراري
التوزيع الثنائي n=5 p=1/4، احسب P(X>=2)
```

تُحفظ الكسور والعشريات بدقتها الأصلية في الحساب النسبي المحدود؛ التوزيعان الثنائي والطبيعي يعرضان تقريبًا عدديًا عند الحاجة. لا يُفترض استقلال أو تنافٍ أو نمط سحب أو تطبيع جدول ناقص. لا تمنح نتيجة ناقصة الدقة أو تحت المجال العددي شارة تحقق زائفة. أمثلة الصيغ والحدود وتقسيم مهام التطوير: [docs/PROBABILITY.md](docs/PROBABILITY.md).

## الأعداد العقدية والتحويلات

- الأشكال الجبري والمثلثي والأسي في بطاقات رياضية متجاورة على الشاشة الواسعة ومتراصة على الهاتف، مع الطويلة والعمدة الرئيسية ضمن ]−π،π].
- قانون أويلر ومتطلباته وتحويل الأسّي إلى جزأين حقيقي وتخيلي، ودستور ديموافر للقوى الصحيحة الكبيرة. لا تُوسّع القوى الضخمة ولا تُحسب قوة إضافية لمجرد عرض النتيجة.
- تبسيط مضاعفات الزوايا وتخفيض قوى sin/cos بأويلر وديموافر، والجمع والطرح والضرب والقسمة والمرافق والمقلوب.
- ربط اللاحقة بالنقطة والشعاع، والمسافة بطويلة الفرق، والزاوية الموجهة بعمدة النسبة. رسوم متجهات، ومراكز تحويل ودائرة الجذور/الدوران.
- الانسحاب والتحاكي والدوران حول مركز صريح. الدرجة/الراديان/الغراد الصريحة تتقدم على الإعداد؛ الزاوية المحتوية على π بلا وحدة أخرى تُفسر بالراديان.
- حل المعادلات في ℝ افتراضيًا؛ عند Δ<0 للمعادلة التربيعية يظهر **مستحيلة الحل** ومجموعة حل فارغة، مع متابعة صريحة للحل في ℂ. المعادلة العقدية تقبل أيضًا معاملات عقدية من الدرجة الأولى أو الثانية.
- تحتفظ المتابعات بالعدد الناتج واللاحقات المسماة والمجموعة الهندسية النشطة. لا يُختار جذر واحد نيابةً عن المستخدم عند تعدد الجذور.

```text
اكتب الأشكال الثلاثة للعدد العقدي z=1+i
احسب e^(i*pi/3) باستخدام قانون أويلر
احسب z^2024 بديموافر حيث z=1+i
بسط cos(3theta) وsin(3theta) بديموافر
بسط sin(theta)^3 باستخدام أويلر
احسب العمليات الجبرية للعددين z1=3+2i وz2=1-i
احسب المسافة بين A(1,2) وB(4,6)
احسب زاوية BAC في المستوي العقدي z_A=1+i وz_B=2+i وz_C=1+2i
انسحاب z=1+i بشعاع b=2-i
تحاكي z=2+i مركزه omega=1 ونسبته k=-2
دوران z=1+i حول المبدأ بزاوية 90 درجة
حل المعادلة x^2+1=0 في الأعداد الحقيقية
حل المعادلة z^2+(1+i)*z+i=0 في الأعداد العقدية
```

الحدود المقصودة: القيمة المطلقة للأس الصحيح حتى 10¹²، رتبة الجذور حتى32، ورتبة التبسيط المثلثي حتى12. تبقى النتائج التي تتجاوز المجال العددي رمزية دون شارة تحقق مزيفة. البيانات الناقصة أو الصفر في مقام/زاوية تستدعي توضيحًا. حُذفت عبارات الحل المحلي وتعليمات لوحة المفاتيح الثابتة من الواجهة؛ بقي سلوك Enter وShift+Enter نفسه.

## أمثلة من المربع الوحيد

```text
جد مشتق f(x)=x^3-3x+1 ونظّم جدول تغيراته
حل المعادلة 2x^2-5x+3=0
احسب تكامل x e^x من 0 إلى 1
جد نهاية (x^2-1)/(x-1) عندما x تؤول إلى 1
جد محدد ومقلوب المصفوفة [[1,2],[3,4]]
حل المعادلة z^2+2z+5=0 في مجموعة الأعداد العقدية
كيس فيه 3 كرات حمراء و5 بيضاء سُحبت كرتان معًا، جد احتمال أن تكونا مختلفتي اللون
متتالية حسابية حدها الأول 3 وأساسها 4، جد مجموع أول 20 حدًا
جد المسافة بين النقطة A(1,2,3) والمستوي 2x-y+2z-5=0
احسب sin(30°)+√2
```

أمثلة إضافية:

```text

```

إذا لم تكفِ المعطيات، تظهر أسئلة توضيح قصيرة قابلة للنقر بدل جواب مفترض. ليست كل صياغة لغوية أو كل مسألة رمزية مدعومة؛ يُفضّل تحديد المطلوب والمتغيرات والحدود صراحةً. الرسم عينة عددية للتوضيح، والفحص العددي ليس برهانًا عامًا.

## بنية المصدر

```text
src/
  App.tsx                        المحادثة الوحيدة وإدارة الأدوات والحالة
  components/chat/               إدخال عربي/رياضي، إجابات، رسوم، ومراجعة الصور
  components/probability/        اللوحة العائمة وعارض الاحتمالات الداخلي
  components/common/             KaTeX وMathLive والخطوات وحواجز الأخطاء
  components/{الأقسام السابقة}/  عوارض نتائج داخلية، بلا صفحات تنقل
  solver/
    parser.ts                    تطبيع العربية والأرقام وLaTeX وتقسيم الطلبات
    router.ts                    مرشحات محركات مرتبة بالثقة
    extractors/                  استخراج معطيات كل عائلة مسائل
    orchestrator.ts              تشغيل المحركات ودمج النجاح الجزئي والسياق
    runners.ts                   المحولات إلى المحركات الأصلية
    composer.ts                  صياغة الجواب والمتابعات والنسخ
    client.ts, solver.worker.ts  Worker كسول، إلغاء، مهلة وحفظ مؤقت محدود
    math.ts, validation.ts       تحليل آمن وفحوص عددية وتحقق من التخزين
    ocr.ts                       قارئ صور محلي قابل للإلغاء
  hooks/useOfflineSpeech.ts      سياسة الإملاء المحلي فقط
  utils/                         المحركات الرياضية ودليل القوانين وlocalDB
  assets/ocr/                    بيانات OCR محلية مرخّصة
```

تفاصيل التصميم والحدود: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). الحزمة الحالية اجتازت TypeScript الصارم و596 اختبار Node و100 اختبار متصفح لكل من HTTP وfile://. نتائج التحقق وإعادة تشغيلها: [docs/QA.md](docs/QA.md). إشعارات التبعيات: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## التخزين والخصوصية

التخزين محلي ومحدود: آخر 24 رسالة سؤال/جواب، 150 نتيجة محفوظة يدويًا، اسم وإعدادات. محادثة جديدة لا تمسح سجل النتائج. لا تُرفع الصورة أو النص أو الصوت إلى خدمة. وضع التصفح الخاص أو نقل ملف HTML أو مسح بيانات المتصفح قد يفقد التخزين؛ تصدير السجل متاح من أداته. العمل الحسابي وقارئ الصور قابلان للإيقاف.
